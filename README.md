# Сборщик контента

Учебная практика, контрольная точка «Деплоймент»: HTTP-клиент и сервер для сбора информации из интернета.

## Как работает

1. На сервере в `keywords.json` хранится список ключевых слов, каждому соответствует несколько URL.
2. Клиент отправляет ключевое слово, сервер возвращает список URL (`GET /api/keywords/:word`).
3. Пользователь выбирает URL, сервер скачивает страницу и потоком передаёт её клиенту (`GET /api/download?url=…`); размер передаётся в заголовке `X-Content-Length`.
4. Клиент читает поток через `fetch` и `ReadableStream`, показывает размер, процент, скорость и сохраняет страницу в LocalStorage.
5. Сохранённые страницы видны в списке и открываются без интернета.

## Обработка ошибок

| Ситуация | Что видит пользователь |
|---|---|
| ключевое слово не найдено | сообщение и список доступных слов (404) |
| адрес не из списка | отказ (400) — сервер не скачивает произвольные адреса |
| сайт вернул ошибку | «Сайт ответил ошибкой N» (502) |
| сайт не ответил за 15 секунд | сообщение о тайм-ауте (504) |
| страница больше 5 МБ | отказ (413) |
| нет интернета | индикатор «офлайн», поиск и скачивание блокируются, сохранённое доступно |
| сервер недоступен | «Сервер недоступен» |
| переполнен LocalStorage | просьба удалить старые страницы |

Загруженные страницы показываются в изолированном `iframe` с атрибутом `sandbox`, поэтому их скрипты не выполняются.

## Запуск локально

Нужен Node.js 18 или новее.

```
npm install
npm start
```

Открыть http://localhost:3000. Порт можно задать переменной окружения `PORT`.

## Деплой

Публичная версия работает на Cloudflare Pages: статика из `public/`, а серверная часть — Pages Functions в `functions/api/[[path]].js` с теми же маршрутами, что и в `server.js`. Страница скачивается целиком (до 5 МБ), после чего отдаётся клиенту потоком с точным размером в `X-Content-Length`.

```
npx wrangler pages deploy
```

## Стек

Node.js, Express (локально), Cloudflare Pages Functions (публично), клиент на чистом JavaScript (Fetch API, Streams API, LocalStorage), без сборки.

Интерфейс сделан по принципам Apple HIG: светлая и тёмная темы по системным настройкам, раскладка «боковая панель + просмотр» (на телефоне просмотр открывается отдельным экраном), продуманные состояния загрузки, пустого списка и ошибок, удаление с отменой, управление с клавиатуры (`/` — поиск, стрелки — по списку, Delete — удалить), поддержка «уменьшения движения» и «уменьшения прозрачности».
